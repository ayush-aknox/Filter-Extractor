# Findings Filter Capture

Chrome extension that captures the filters applied on the AccuKnox CSPM Findings
page and exports them as a `{ filter, input, data_field, column_name }` block,
in the same shape used by `data/findingsFilter.js`.

## Load it

1. `chrome://extensions` → enable Developer mode → **Load unpacked** → select this `Filter-Extractor/` folder.

## Use it

1. Open the Findings page and apply your filters (this fires a `finding-dashboard-v2` request).
2. Click the extension icon.
3. Pick a data type (or leave "Auto-detect"), click **Capture Latest Filters**.
4. Click **Copy** to copy the generated block.

## Files

- `background.js` — watches network requests, stores the latest `finding-dashboard-v2` URL per tab.
- `popup.html` / `popup.js` — UI: capture, format, copy.
- `filterMap.js` — generated from `data/findingsFilter.js` (filter/data_field/column_name per
  data type). There's no regen script yet; if `data/findingsFilter.js` changes, this needs to be
  regenerated by hand.
